# 🐾 PawLife

**PawLife** is a comprehensive Android pet care companion app built with Kotlin and Jetpack Compose. It helps pet owners manage every aspect of their pet's life — from health records and vet appointments to feeding schedules, activity tracking, and community interaction.

---

## ✨ Features

- **Pet Profiles** — Create and manage detailed profiles for multiple pets
- **Health Records** — Track vaccinations, medications, and vet visits
- **Feeding Schedules** — Set reminders and log meals
- **Activity Tracker** — Monitor walks, playtime, and exercise
- **Vet Finder** — Locate nearby veterinary clinics
- **Community** — Connect with other pet owners
- **Reminders & Notifications** — Never miss an appointment or feeding time

## 🚀 Getting Started

### Prerequisites
- Android Studio Hedgehog or later
- JDK 11+
- Android SDK 35

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Shobanherbert7/PawLife.git
   ```
2. Open in Android Studio
3. Sync Gradle files
4. Run on an emulator or physical device (API 24+)
